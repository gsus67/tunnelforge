Gateway WISP Access

Administrador SSH para operar varios gateways y servidores desde una sola ventana: conexiones, terminal, archivos, túneles y herramientas.

Operación

  • Terminal SSH integrada con historial de comandos.
  • Gestor SFTP para subir, bajar y administrar archivos.
  • Túneles locales por servidor con acceso rápido a paneles web.
  • Tráfico de red real del servidor en el Dashboard, expresado en Mbit/s.
  • Monitoreo centralizado con preparación por fases, verificación de servicios y resumen nativo responsive de CPU, RAM, disco y tráfico.
  • Peers WireGuard en lista compacta con nombres de WGDashboard/configuración WireGuard, RX/TX en Mbit/s y último handshake en tiempo real.
  • WireGuard integrado con perfiles, importación/exportación .conf, múltiples peers, autoconexión, generación de keys/PSK y tráfico en tiempo real. En Windows el motor viene embebido en la app; Linux utiliza wireguard-tools del sistema.
  • Acceso web local opcional para operar la misma interfaz desde teléfono, tablet u otra PC de la LAN.

Seguridad

  • Keys ED25519 y verificación TOFU de la huella del host.
  • Hardening SSH reversible con validación antes de aplicar cambios.
  • Contraseñas guardadas cifradas localmente.
  • PrivateKey y PresharedKey de WireGuard cifradas en almacenamiento local y en backups portables; hooks importados desactivados hasta autorización explícita.
  • Updates privados verificados con firma Ed25519 y SHA-256.
  • Servidor web LAN apagado por defecto, autenticado por código y sin exponer el token maestro al navegador remoto.

Herramientas

  • Cargar scripts locales al servidor y ejecutarlos viendo la salida en Terminal.
  • Test de velocidad a Internet desde el servidor conectado.
  • Firewall: detección de UFW, firewalld y nftables con apertura/cierre seguro de puertos.
  • Selector de servidor para resolver puertos compartidos en localhost:puerto.
  • Más utilidades pueden añadirse sin recargar el Dashboard.

Atajos

  • Ctrl + Enter guarda el perfil que estás editando.
  • Esc cierra Terminal, Archivos, Herramientas y diálogos.
  • Un clic en un comando del historial vuelve a enviarlo a la Terminal.
  • La casilla verde en un conectado lo convierte en destino de localhost.

Contraseña requerida

¿Asegurar SSH ahora?

La nueva key ya fue instalada y comprobada. Gateway puede endurecer el acceso SSH para que el servidor deje de aceptar contraseñas.

✓ PubkeyAuthentication yes — mantiene el acceso por key.
✓ PasswordAuthentication no — bloquea login por contraseña.
✓ KbdInteractiveAuthentication no — bloquea autenticación interactiva.
✓ PermitRootLogin prohibit-password — root queda permitido solo mediante key.

Gateway crea un respaldo de /etc/ssh/sshd_config, aplica el bloque seguro con prioridad, valida con sshd -t, recarga SSH y hace una prueba real intentando autenticarse otra vez con contraseña. Solo confirma el endurecimiento si la key funciona y la contraseña ya es rechazada. Root no se desactiva por completo: queda disponible solo con key.
